How to learn this course and run the laptop projects

Your weekly routine: spend about 3 hours reading and tracing, 4 hours writing and debugging, 6–8 hours building the project, and 2–3 hours testing and explaining it. Begin with the guided lessons in order. Practise the worked example before the independent task. Optional stretch challenges in Weeks 1–4 are for after you finish Week 4.

First laptop setup: install Python 3.11 or newer. Extract a project ZIP, open a terminal in that folder and read its README. Create an environment with python -m venv .venv. Activate it using the Windows or macOS/Linux command in the README, then install the listed requirements. Run the project and its tests before changing it.

For webpages: Week 9 opens in a browser. Weeks 10–12 and 16 need the Python API running: python -m uvicorn app:app --reload. Open http://127.0.0.1:8000 while that terminal stays running. Ctrl+C stops the server. Opening the HTML file alone does not start an API.

Git habit: inspect git status and git diff, add only intended files, and make a small commit after a tested change. Keep credentials and private data out of Git. A local commit is separate from uploading to your own GitHub account.

Use AI thoughtfully: attempt the exercise first. Ask for an explanation or a hint, check suggested code with tests, and explain the change yourself. The final project uses a small classifier and source-based search; it does not train an LLM. No AI provider key is required.

Before applying: show a working demo, setup instructions, tests and honest limitations. Ask someone to give you an unfamiliar change request and review the result. Checks here are practice evidence; they cannot guarantee an internship.
